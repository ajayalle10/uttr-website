How to use

Up and running in 2 minutes

Install

  1. Download Uttr-Setup.exe.
  2. Double-click it. Uttr installs in a few seconds. No admin password is needed.
  3. If Windows shows "Windows protected your PC", click More info, then Run anyway. This blue screen appears for new apps that aren't signed with a paid certificate. Uttr's full source code is public on GitHub.
  4. Done! You'll see "Uttr is ready" at the bottom of your screen, and the Uttr logo near the clock (it may be under the ^ arrow).

Use

  1. Select some text in any app.
  2. Press Ctrl + Alt + R. The Uttr bar slides up and reads it aloud.
  3. Control it from the bar: pause, change speed or stop. Or just press Esc.

Install

  1. Download uttr.zip and unzip it (right-click → Extract All on Windows, double-click on Mac).
  2. Move the uttr folder somewhere permanent, like Documents. Don't delete it later, because your browser loads Uttr from it.
  3. Open your extensions page: type chrome://extensions (or edge://extensions) in the address bar.
  4. Turn on "Developer mode": top-right in Chrome, left sidebar in Edge.
  5. Click "Load unpacked" and choose the uttr folder.
  6. Pin it: click the 🧩 puzzle icon, then the 📌 pin next to Uttr.

Uttr isn't in the Chrome Web Store yet, which is why it's installed this way. One-click store versions are coming.

Use

  1. Open any website, and refresh tabs that were already open.
  2. Select some text with your mouse. Uttr reads it straight away. No shortcut needed.
  3. Select something else to switch, or press Esc to stop.

FAQ

Questions, answered

Is Uttr free?

Yes. Both the Windows app and the browser extension are completely free, with no ads.

Is my text sent anywhere?

No. Uttr uses the voices built into your computer and browser, so your text stays on your device. There's no account, tracking or analytics. The Windows app only connects to GitHub to check for updates. (Some browser voices marked "Google" or "Online" are provided by your browser over the internet. Pick a different voice to keep everything offline.)

Why does Windows show "Windows protected your PC"?

Windows shows that screen for any new app that isn't signed with a paid code-signing certificate. Click More info → Run anyway. Uttr's complete source code is public on GitHub for anyone to check.

How does the Windows app read text from other apps?

When you press the shortcut, Uttr briefly copies your selection (like pressing Ctrl+C), reads it, and then puts your clipboard back exactly as it was. Nothing is stored.

Can I change the shortcut from Ctrl + Alt + R?

Yes. Click the Uttr icon near the clock, then Change under Activation shortcut, and press any combination that includes Ctrl, Alt or the Windows key. If another app already uses it, Uttr will tell you.

How do I get more or better voices?

On Windows, go to Settings → Time & language → Speech → Add voices. New voices then appear in Uttr's voice list.

It doesn't read in one particular app. Why?

A few places don't allow copying, such as password fields, some protected documents, and apps running "as administrator". Everything else should work.

Is there a Mac, iPhone or Android version?

Not yet. The browser extension works on Mac in Chrome, Edge and Brave today. A Mac app and an Android version are on the roadmap.

What about Firefox and Safari?

A Firefox version is ready and on its way to Firefox Add-ons. Safari isn't supported yet.

How do I uninstall?

Windows app: Settings → Apps → Installed apps → Uttr → Uninstall. Extension: open chrome://extensions, click Remove on Uttr, then delete the uttr folder.
