# Uttr website

The official website for **Uttr**, by Ajay Alle: **https://ajayalle10.github.io/uttr-website/**

A single, static page (HTML, CSS and a little JavaScript, with no build step) hosted free on GitHub Pages.

| File | What it does |
|---|---|
| `index.html` | The whole page: hero, products, features, use cases, how-to guides, FAQ, Terms & Conditions |
| `styles.css` | Black, red and white theme from the Uttr logo; responsive down to phone width |
| `script.js` | The Windows / extension tabs, a hint for Mac and phone visitors, and the footer year |
| `images/` | Logo, screenshots and the floating-bar images |

**Downloads** link straight to the latest GitHub release of each project, so the site never needs updating when a new version ships:
- Windows app: [uttr-desktop](https://github.com/ajayalle10/uttr-desktop), via `releases/latest/download/Uttr-Setup.exe`
- Browser extension: [uttr-chrome-extension](https://github.com/ajayalle10/uttr-chrome-extension), via `releases/latest/download/uttr.zip`

**To edit:** change the files, commit, and push to `main`. GitHub Pages republishes in about a minute.
